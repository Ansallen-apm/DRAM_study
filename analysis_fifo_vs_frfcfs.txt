Analysis of FIFO vs FR-FCFS for 4-Master Sequential Read on LPDDR4-6400 (Buffer Scaling Investigation)

Configuration:
- DRAM: LPDDR4-6400 x64 (tCK = 0.3125ns)
- Masters: 4
- Traffic: Sequential Read, 1KB Burst
- Offsets: 0, 128KB, 256KB, 384KB
- Master Clock: 1000 MHz
- Request Count: 10,000 requests per master
- Max Pending Requests (per master): 32
- Total Potential Outstanding Requests: 128 (4 * 32)

Empirical Results (Buffer Size Sweep):

1. Buffer Size = 128 (Matches Total Pending Limit)
   - FIFO: 55.34%
   - FR-FCFS: 82.07%
   - Behavior:
     - The buffer size exactly matches the maximum load. The controller applies backpressure when full.
     - This backpressure likely synchronizes the masters, enforcing a round-robin injection pattern into the buffer.
     - FIFO sees interleaved requests (M0, M1, M2, M3...) -> Row Conflicts -> Low/Medium Performance.
     - FR-FCFS reorders these to optimize row hits -> High Performance.

2. Buffer Size = 256 (Oversized - 2x Total Pending)
   - FIFO: 90.56%
   - FR-FCFS: 90.89%
   - Behavior:
     - The buffer is larger than the maximum possible number of requests the masters can issue (128).
     - The controller *never* applies backpressure.
     - **Simulation Artifact:** In the absence of backpressure, the SystemC simulation likely executes each master's generation loop in batches within the delta cycles or simply allows one master to dump all its pending requests (up to 32) into the buffer before the next master gets a turn to write to the port.
     - Resulting Buffer Content: [M0_req1...M0_req32, M1_req1...M1_req32, ...].
     - Even a FIFO scheduler processes this "batched" stream as perfect row hits.
     - **Real World Note:** In a real hardware NoC/Bus, this behavior depends entirely on the arbiter and master clock alignment. If masters are truly asynchronous and interleaved, FIFO would *not* improve this dramatically. This result is specific to the simulation's unconstrained injection behavior.

Conclusion:
- **Constraint Mode (Buffer <= 128):** Realistically models contention. FR-FCFS (82%) is vastly superior to FIFO (55%).
- **Unconstrained Mode (Buffer > 128):** Models a system with infinite buffering. The simulation introduces artificial batching, making FIFO perform deceptively well (~91%).
- **Recommendation:** For valid scheduler comparison, the buffer size should be constrained (e.g., 64 or 128) to force the schedulers to handle actual interleaving/contention, which is the scenario where scheduling algorithms matter.
