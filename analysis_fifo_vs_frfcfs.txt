Analysis of FIFO vs FR-FCFS for 4-Master Sequential Read on LPDDR4-6400 (High Frequency)

Configuration:
- DRAM: LPDDR4-6400 x64 (tCK = 0.3125ns)
- Masters: 4
- Traffic: Sequential Read, 1KB Burst
- Offsets: 0, 128KB, 256KB, 384KB
- Master Clock: 1000 MHz (increased from 200 MHz)

Empirical Results (DRAMSys Simulation - 1000 MHz):
- FIFO Utilization: 32.22% (Bandwidth: 16.47 GB/s)
- FR-FCFS Utilization: 50.83% (Bandwidth: 25.98 GB/s)

Comparison with 200 MHz Results:
- The results are identical to the 200 MHz simulation.
- 200 MHz: FIFO ~32.22%, FR-FCFS ~50.83%
- 1000 MHz: FIFO ~32.22%, FR-FCFS ~50.83%

Analysis:
Why did increasing the master clock frequency not improve performance?

1. Memory Bound System:
   - The memory system is already saturated (or limited by latency overheads) even at 200 MHz request injection rates.
   - At 200 MHz, the masters are capable of generating requests faster than the DRAM can service them (given the Row Conflict overheads).
   - Increasing the injection rate to 1000 MHz only fills the request buffers faster, but the drain rate (DRAM service rate) remains constant because it is determined by the DRAM timings (tRC, tRAS, tCAS) and the scheduling efficiency.

2. Latency vs Bandwidth:
   - In the FIFO case, the bottleneck is the `tRC` (Row Cycle Time) required for every transaction due to thrashing. The DRAM simply cannot cycle banks faster.
   - In the FR-FCFS case, the bottleneck is still the DRAM timings and the limited batching size (8 requests).
   - The request buffer size (32) allows for the same amount of look-ahead reordering regardless of how quickly those 32 requests arrived.

3. Saturation:
   - Since the utilization didn't change, it confirms that the "offered load" was already sufficient to saturate the memory controller's effective throughput capability under these specific access patterns. The bottleneck is the DRAM protocol and the bank conflicts, not the master's generation speed.

Conclusion:
Increasing the master clock to 1000 MHz had no effect on the utilization rate. The system performance is dominated by the DRAM timing constraints and the row conflict penalties inherent to the access pattern, rendering the faster request injection irrelevant for bandwidth purposes in this specific scenario.
