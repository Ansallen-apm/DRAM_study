Analysis of FIFO vs FR-FCFS with Small Bursts (256B) and Per-Bank Refresh

Configuration:
- DRAM: LPDDR4-6400 x64
- Traffic: Single STL Trace Player (Strict Interleaving)
- Burst Size: 256 bytes (Reduced from 1KB)
- Refresh Policy: Per Bank
- Trace Pattern: 0, 128KB, 256KB, 384KB, 256B, 128KB+256B...

Results (Utilization vs Buffer Size):

| Buffer Size | FIFO Utilization | FR-FCFS Utilization |
| :--- | :--- | :--- |
| 64 | 10.13% | 69.18% |
| 128 | 15.12% | 82.07% |
| 256 | 45.25% | 90.84% |

Detailed Analysis:

1. FIFO Sensitivity to Burst Size:
   - With 1KB bursts (previous run), FIFO achieved ~86% utilization even with interleaving because the large data transfer (64 cycles) amortized the row conflict overhead.
   - With 256B bursts, data transfer is only 16 cycles (2ns).
   - The Row Cycle overhead (tRC approx 50-60ns) is now DOMINANT.
   - Efficiency drops catastrophically to ~10-15% with small buffers.
   - Even with Buffer 256 (where pipelining is maximized), FIFO only reaches ~45%.
   - This clearly demonstrates that **FIFO performance is highly dependent on burst length** in high-contention scenarios. Small bursts expose the true cost of thrashing.

2. FR-FCFS Resilience:
   - FR-FCFS maintains high performance (69% - 91%) even with small bursts.
   - It effectively reorders the request stream to group accesses to the same row.
   - Buffer 64: 69% (Good, but limited look-ahead).
   - Buffer 128: 82% (Excellent).
   - Buffer 256: 91% (Near optimal).
   - The scheduler successfully hides the row conflicts by processing batches, proving its value is *critical* for small-transaction workloads.

3. Buffer Size Impact:
   - **FIFO:** Improvements (10% -> 15% -> 45%) are due to pipelining and hiding some latency behind bus transfers, but it never overcomes the fundamental thrashing limit.
   - **FR-FCFS:** Improvements (69% -> 82% -> 91%) are due to finding larger batches of row hits. With Buffer 256, it can likely see enough requests to fully saturate the bank interleave capabilities or form long row-hit sequences.

Conclusion:
Reducing the request size to 256 bytes dramatically widened the performance gap. FIFO collapses to <15% efficiency under normal buffering (64/128), while FR-FCFS sustains >80%. This confirms that for fine-grained random/interleaved traffic, an intelligent scheduler (FR-FCFS) is indispensable.
